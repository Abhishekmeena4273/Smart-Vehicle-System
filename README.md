# 🚗 Smart Vehicle Management System

A comprehensive backend system for managing vehicle fleets, services, inventory, and routes using efficient Data Structures.

## 🛠️ Tech Stack
- **Language:** Java
- **Interface:** CLI (Command Line Interface)
- **Data Persistence:** CSV File I/O

## 📊 Data Structures Used
| Module | Data Structure | Complexity |
|--------|---------------|------------|
| Vehicle Management | Hash Table | O(1) Search |
| Service Scheduling | Linked List | O(n) Traversal |
| Inventory | Binary Search Tree | O(log n) Search |
| Route Management | Graph (Dijkstra) | O(E + V log V) |
| Activity Logs | Queue | O(1) Insertion |

## 🚀 How to Run
1. Clone the repository.
2. Open in VS Code.
3. Run `RunProject.bat`.

## 📂 Features
- Automatic Audit Logging
- Data Persistence (Save/Load)
- Shortest Path Calculation
- Sorted Inventory Management
